这次来学习两个重要的辅助函数

```c++
/*将 __bytes 上调至最邻近的 8 的倍数*/
static size_t  _S_round_up(size_t __bytes) 
{ return (((__bytes) + (size_t) _ALIGN-1) & ~((size_t) _ALIGN - 1)); }

/*返回 __bytes 大小的chunk块位于 free-list 中的编号*/ 
static  size_t _S_freelist_index(size_t __bytes) {
return (((__bytes) + (size_t)_ALIGN-1)/(size_t)_ALIGN - 1); }
```

先看_S_round_up这个函数。

在通过空间配置器开辟内存时所申请的字节大小会经过 _S_round_up的封装，把容器需要的空间上调至最近的8的倍数，小于128字节的都是内存池里分配的，从8字节开始，到128字节位置，每8字节分一块。

```c++
enum { _ALIGN =8};
static size_t  _S_round_up(size_t __bytes) 
{ return (((__bytes) + (size_t) _ALIGN-1) & ~((size_t) _ALIGN - 1)); }

```

先对_ALIGN进行类型强转成一个无符号整数4字节（比如8转为00000000 00000000 00000000 00001000)，减一为00000000 00000000 00000000 00000111，最后取反11111111 11111111 11111111 11111000。因为后面会进行按位与操作，希望把高位的1留下来，如果高位都是0，那么跟谁与都是0。

让1~8映射到8，9~16映射到16，以此类推。

比如__bytes是1，00000000 00000000 00000000 00001000 & 11111111 11111111 11111111 11111000 为8

__bytes是9，00000000 00000000 00000000 00010000 & 11111111 11111111 11111111 11111000 为16

所以可以做到内存对齐的效果

然后看_S_freelist_index

```c++
/*返回 __bytes 大小的chunk块位于 free-list 中的编号*/ 
static  size_t _S_freelist_index(size_t __bytes) {
return (((__bytes) + (size_t)_ALIGN-1)/(size_t)_ALIGN - 1); }
```

当我们想申请内存的时候，需要知道是从哪个自由链表的块中去申请，当我们想要申请1个字节，就是从以8为大小的内存块中去分配的。

比如__bytes为1,(1+7)/8-1，从编号为0的内存块中去申请，也就是大小为8字节的内存块，最后返回这个下标

这次来学习两个重要的辅助函数

```c++
/*将 __bytes 上调至最邻近的 8 的倍数*/
static size_t  _S_round_up(size_t __bytes) 
{ return (((__bytes) + (size_t) _ALIGN-1) & ~((size_t) _ALIGN - 1)); }

/*返回 __bytes 大小的chunk块位于 free-list 中的编号*/ 
static  size_t _S_freelist_index(size_t __bytes) {
return (((__bytes) + (size_t)_ALIGN-1)/(size_t)_ALIGN - 1); }
```

先看_S_round_up 这个函数。

在通过空间配置器开辟内存时，申请的字节大小会经过 _S_round_up 的处理，把需要的空间上调至最近的 8 的倍数。小于 128 字节的内存都由内存池管理，内存块从 8 字节开始，到 128 字节为止，每 8 字节划分一块。

```c++
enum { _ALIGN =8};
static size_t  _S_round_up(size_t __bytes) 
{ return (((__bytes) + (size_t) _ALIGN-1) & ~((size_t) _ALIGN - 1)); }
```

先对`_ALIGN-1`进行类型强转为 size_t 无符号整数（比如 8 转为 00000000 00000000 00000000 00001000)，减一结果为 00000000 00000000 00000000 00000111，最后按位取反得到 11111111 11111111 11111111 11111000。

按位与操作会保留数字的高位部分，清零低位，以此实现内存对齐。

函数可以将 1~8 映射到 8，9~16 映射到 16，以此类推。

比如__bytes 是 1，00000000 00000000 00000000 00001000 & 11111111 11111111 11111111 11111000 结果为 8

__bytes 是 9，00000000 00000000 00000000 00010000 & 11111111 11111111 11111111 11111000 结果为 16

通过这种方式就可以实现内存对齐的效果。

------

然后看_S_freelist_index

```c++
/*返回 __bytes 大小的chunk块位于 free-list 中的编号*/ 
static  size_t _S_freelist_index(size_t __bytes) {
return (((__bytes) + (size_t)_ALIGN-1)/(size_t)_ALIGN - 1); }
```

当我们申请内存时，需要找到对应的自由链表块来分配。申请 1 个字节时，就会使用 8 字节大小的内存块进行分配。

比如__bytes 为 1，(1+7)/8-1=0，从编号为 0 的自由链表中分配，也就是 8 字节的内存块，最终返回对应的下标。

# TinyWebServer学习笔记与踩坑记录

## 1. ET模式数据读取问题
**问题**：ET模式下一次recv只能读取部分数据，导致请求解析不完整
**解决**：必须循环调用recv直到返回EAGAIN或EWOULDBLOCK，表示数据已读尽

## 2. 多线程事件竞争问题
**问题**：同一个连接的读写事件可能被多个线程同时处理，导致数据混乱
**解决**：使用EPOLLONESHOT标志，保证一个连接同一时间只被一个线程处理，处理完成后重新注册事件

## 3. 内存泄漏问题
**问题**：socket文件描述符没有正确关闭，导致资源泄漏
**解决**：使用std::unique_ptr+自定义删除器管理fd，利用RAII机制自动释放资源

## 4. HTTP解析状态机设计
**问题**：HTTP请求格式复杂，直接解析容易出错
**解决**：采用主从状态机设计，主状态机处理请求行/头/体，从状态机按\r\n切割单行，逻辑清晰易于扩展

## 5. Valgrind警告问题
**问题**：运行时出现"使用未初始化内存"的警告
**解决**：epoll_event结构体在使用前必须用memset清零，避免未初始化的内存被内核读取
